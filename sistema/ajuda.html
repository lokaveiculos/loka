🚀 Primeiros passos

Para quem está começando a usar o sistema

Entrando no sistema

  1. Acesse lokaveiculos.com.br/sistema/gestao.html
  2. Digite seu usuário e senha e entre
  3. A tela inicial é o Dashboard, com o resumo do dia

Conhecendo a tela

  • Menu lateral: todas as telas, em 3 grupos (Principal, Documentos, Público)
  • + NOVO (topo): atalho para criar um aluguel
  • Faixa vermelha no topo: alertas de locações vencidas ou vencendo
  • Rodapé: seu nome e perfil, a versão do sistema, botões Usuários/Sair e Backup/Restaurar
Dica: o fluxo básico do dia a dia é — cadastrar o cliente → criar o aluguel → gerar o contrato → fazer o checklist na entrega → e ao final, encerrar a locação.

📊 Dashboard

Menu → Dashboard (tela inicial)

Resumo do negócio em tempo real: total de veículos, clientes, aluguéis ativos e alertas.

O que observar diariamente

  • A faixa de locações vencidas — cada uma exige ação (cobrar, prorrogar ou encerrar)
  • Os vencimentos em até 3 dias — combine devolução ou renovação com o cliente

O Dashboard só exibe. Para agir, clique no módulo correspondente do menu.

Cadastrar

  2. Preencha nome/razão social, CPF ou CNPJ, CNH, telefone e endereço
  3. Salve

🔑 Aluguéis Ativos

Menu → Aluguéis Ativos · atalho + NOVO no topo

A tela mais importante: todas as locações em andamento, com cliente, veículo/placa, tipo, datas, dias restantes, valor e pagamento.

Criar um aluguel

  1. + NOVO → escolha o cliente (precisa estar cadastrado)
  2. Escolha o veículo (só aparecem os disponíveis)
  3. Defina tipo (Diária/Mensal), retirada, devolução e valor → Salvar
O sistema bloqueia datas invertidas (devolução antes da retirada) na criação e na prorrogação.

Botões de cada linha

BotãoFunção
📅Prorrogar: estende a devolução e gera o termo de prorrogação
💳Pagamento: marca Pago/Pendente
🔴Encerrar: finaliza a locação (veja abaixo)
🗑Excluir: apaga sem histórico — só para lançamentos errados

Encerrar uma locação

  1. Clique em 🔴 na linha do aluguel
  2. Informe data de devolução, KM, condição e observações
  3. Confirme em Encerrar Locação

Automaticamente: o registro vai para Aluguéis Encerrados, o veículo volta a disponível e o sistema confirma a gravação no banco (mostra aviso se falhar).

Filtros e link público

  • Filtros TODOS / DIÁRIA / MENSAL + busca por cliente ou veículo
  • Link para compartilhar: página somente-leitura para o cliente acompanhar

Botão 🔓 Liberar

Disponível nas telas Veículos e Frota Ativa, para quando o veículo volta. O sistema identifica a situação sozinho:

SituaçãoO que acontece
Veículo com aluguel ativoAbre a tela de encerramento já preenchida: informe a data de devolução e o KM. O contrato vai para o histórico, o veículo fica disponível e o KM é atualizado no cadastro.
Veículo em contrato com várias placasRetira apenas aquela placa do contrato e libera o veículo. O contrato segue ativo com as demais placas.
Veículo sem aluguel (status errado)Apenas corrige o status para Disponível.
O KM atual do veículo já vem sugerido no campo — confira e ajuste se necessário, pois ele atualiza o cadastro do veículo.

🚛 Frota Ativa

Menu → Frota Ativa · restrito a admin/master

Visão consolidada de toda a frota com documentação:

  • RENAVAM, Chassi, Ano/Mod, Alienado: documentação de cada placa
  • Locatário/Info: quem está com o veículo agora (vem do aluguel ativo)
  • Entrega e KM Entrega: quando e com que quilometragem o veículo foi entregue ao cliente atual
Veículo "sem locatário" = sem aluguel ativo registrado para a placa. Crie o aluguel para vincular à empresa/cliente.

🧾 Faturas

Menu → Faturas

Criar uma fatura

  1. Nova fatura → selecione o cliente e o Período de Referência (mês)
  2. Marque os veículos; para cada um: qtd de dias/meses, valor unitário, seguro, desconto
  3. Subtotais e total calculam sozinhos → salve e imprima

Deduzir dias parados na oficina

  1. Na coluna "Dias parado", digite os dias que o veículo ficou parado no mês
  2. Clique no botão ↓
  3. O desconto (mensal ÷ 30) × dias entra no campo Desconto
Os dias exatos estão no relatório de Manutenção (coluna "Dias parado").

Juros e multa por atraso

Ative a seção de juros/multa, informe multa (%), juros ao mês (%) e dias de atraso. Padrão usado: 2% multa + 6% a.m. (juros pro rata por dia). O total recalcula na hora.

🔧 Manutenção

Menu → Manutenção

Registrar

  1. + Nova → selecione o veículo
  2. Informe Data de Entrada, Previsão de Retorno e, quando o carro voltar, a Data de Saída da Oficina
  3. Escolha o fornecedor/oficina (ou cadastre pelo botão +)
  4. Tipo, descrição, KM na entrada, custo, pagamento e status (orçamento / em andamento / concluída)
Preencha sempre a Data de Saída quando o veículo voltar — ela alimenta o cálculo de dias parados usado no relatório e na fatura.

Relatório

O relatório obedece aos filtros da tela (busca, status, período, veículo). Mostra Entrada, Saída e Dias parado — com "(na oficina)" em vermelho para quem ainda não saiu — agrupado por veículo com subtotais. O cabeçalho registra os filtros aplicados.

🚨 Multas

Menu → Multas

Importar por PDF

  1. Envie o PDF do órgão de trânsito — o sistema lê as infrações automaticamente
  2. Para cada multa, o sistema cruza a data da infração com os aluguéis (ativos e histórico) e sugere o condutor responsável
  3. Confirme ou ajuste o locatário indicado

Acompanhamento

  • Alertas de prazo: multas com prazo de indicação/recurso vencendo ganham destaque
  • Filtros: por cliente, por finais de placa (multi-seleção) e período
  • Relatório A4: agrupado por cliente, pronto para cobrança

Antes de lançamentos em lote ou correções: ⬇ BACKUP. O Financeiro é o módulo mais sensível.

💾 Backup e dados

Rodapé → botões ⬇ BACKUP e ⬆ RESTAURAR

Onde os dados ficam

Tudo é salvo na nuvem (Firebase) em tempo real. O site apenas exibe as telas — se o site cair, os dados continuam seguros. Cada aparelho guarda também uma cópia local para internet instável.

Backup automático diário (novo!)

O sistema grava sozinho um backup completo uma vez por dia (na primeira vez que alguém abre o sistema no dia), mantendo os últimos 7 dias na nuvem. Nenhuma ação é necessária.

Para o administrador: no Console (F12), listarBackupsAutomaticos() mostra os dias disponíveis e restaurarBackupAutomatico("AAAA-MM-DD") restaura um deles (baixando antes uma cópia do estado atual, por segurança).

Backup manual

  1. ⬇ BACKUP: baixa um arquivo .json com todos os dados — recomendado antes de operações em lote e para guardar cópias externas
  2. ⬆ RESTAURAR: devolve um backup ao sistema (substitui os dados atuais — use com cuidado)

Proteções automáticas

  • Trava de carregamento: impede gravar antes de os dados carregarem
  • Guarda de integridade: aborta gravações que zerariam listas importantes
  • Dupla barreira: contratos encerrados não voltam (bloqueio pela lista de encerrados + histórico)

🔄 Atualizações

Automático a partir da v52

Quando uma nova versão é publicada, todas as páginas abertas se atualizam sozinhas. O sistema detecta a novidade por dois caminhos:

  • Verificação direta no servidor: cada página consulta a cada 5 minutos (e ao voltar o foco na aba) se há publicação nova
  • Aviso em tempo real: quando qualquer aparelho abre a versão nova, os demais são notificados na hora

Nos dois casos aparece o aviso "Nova versão disponível" com contagem de 20 segundos: atualiza sozinho ao final, ou na hora pelo botão Atualizar agora (dá para adiar 1 minuto se estiver no meio de algo).

O número da versão aparece no rodapé (ex: v54-20260806-2019). Em caso de dúvida ou suporte, informe esse número.

"Site not found"Hospedagem fora do ar — os dados estão seguros. Use o sistema local (gestao.html do ZIP) até voltar
Dados diferentes entre aparelhosConfirme que todos estão na mesma versão e recarregue — a sincronização resolve em segundos
